# BullLedgerWeb

Web frontend for the BullLedger project — built with React, TypeScript, and the
TanStack ecosystem. Consumes the BullLedger REST API.

## Getting started

```bash
bun install
cp .env.example .env
bun run dev
```

See [`docs/runbook.md`](docs/runbook.md) for the full runbook: verification commands,
API type regeneration, and how to add an environment variable.
